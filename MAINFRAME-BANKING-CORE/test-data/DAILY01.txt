* DAILY BATCH TRANSACTION FILE - FORMAT:
* POS 01-02: TRAN TYPE (DP=DEPOSIT, WD=WITHDRAW, TR=TRANSFER)
* POS 03-12: ACCOUNT NUMBER
* POS 13-27: AMOUNT (13V2 - 13 integer 2 decimal, no point)
* POS 28-37: TARGET ACCOUNT (for TR only, else spaces)
* POS 38-45: OPERATOR ID
* POS 46-53: DATE (YYYYMMDD)
* POS 54-80: FILLER
*
